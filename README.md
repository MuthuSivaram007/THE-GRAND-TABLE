# 🍽️ THE GRAND TABLE

### Luxury Restaurant Management and Online Food Ordering System

**THE GRAND TABLE** is a web-based restaurant management and online food ordering application designed to provide customers with a convenient food ordering experience and help administrators manage restaurant operations efficiently.

## 📌 Project Overview

The project aims to develop a modern restaurant website where customers can explore food items, view menu details, add products to their cart, and place orders. It also provides an administration interface to manage restaurant-related information.

## ✨ Features

- Attractive and user-friendly interface
- Restaurant food menu display
- Food item selection
- Add and remove items from cart
- Quantity management
- Online food ordering interface
- Admin dashboard
- Restaurant menu management
- Backend server integration
- Database connectivity

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/MuthuSivaram007/THE-GRAND-TABLE.git
```

### 2. Open the Project

```bash
cd THE-GRAND-TABLE
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder and configure the required database connection and environment settings.

### 5. Start the Backend Server

```bash
npm run dev
```
